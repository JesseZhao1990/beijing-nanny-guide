# 北京育儿嫂机构比较手册

在线查看：https://JesseZhao1990.github.io/beijing-nanny-guide/


截至 2026-09-21 的中文公开资料调查网页。现有 125 个机构、品牌或平台档案：91 项有北京育儿业务线索，30 项业务仍待确认，4 个平台入口。条目按品牌及入口组织，不等于同等数量的独立法人。

全部主表条目均已完成定向检索，包含 9 项发现、逐项来源及读取边界、检索关键词、口碑结论、仍需直接核实的问题。记录 636 组网页查询、401 条档案来源；来源可能跨条目重复，不当作独立样本数。

## 范围与证据

- 逐项交叉比对北京市人社局 30 家品牌企业、中国家协北京栏目 73 个单位、北京家协 36 家理事单位，共 139 条名录处理记录。各名单有重叠，也含培训、养老、医院和配套单位，不能简单求和为育儿机构数。
- 另外从机构业务页、58、京东商户、政府招聘及公开报道补充候选。范围不等于北京市全部工商在营家政门店的穷尽普查。
- 原先 56 个条目及此次扩充的候选均保留主体、北京业务、经营线索、换人、退款、费用、人员筛选、督导、联系方式九项调查。未知项明确记录检索结果和缺口。
- 55 个条目有此次小红书站内搜索或正文读取记录；其他条目不声称已经读过小红书正文。页面有 32 条小红书材料记录和 45 条其他材料，包含同源、异地、异工种及商家自述，不能视为同等数量独立育儿订单。
- 同一个帖子涉及多家机构时按品牌分别解释；日期未显示年份则不补造；单方叙述、经营者宣传和独立报道明确区分。未电话联系、未下单、未验证当期合同和候选库存。

联系优先级用于索取合同和比较替换能力，不是服务质量榜，也不依据投诉绝对数量计算质量分数。

## 文件

- `dist/data.json`：全部档案、来源、查询记录、口碑材料和名录筛查，可从网页下载。
- `dist/research.csv`：125 个条目的九项调查、口碑结论、关键缺口、网页查询和来源导出。
- `dist/index.html`、`dist/styles.css`、`dist/app.js`：无第三方运行依赖的响应式界面。

研究原始文件保存在任务专用 Agent Reach 报告目录，未包含浏览器登录信息或凭证。静态网站仅存面向用户的调查结果，不传送搜索输入。

## 本地查看

在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory dist`，浏览器访问 http://127.0.0.1:8765/ 。

四个入口：先联系谁、全部机构、口碑证据、签约前核对。目录支持关键词、联系批次、类型、北京业务状态、体验证据筛选；每家可展开完整档案。

## GitHub Pages 发布

网站由 GitHub Actions 将 `dist/` 发布到 GitHub Pages。推送到 `main` 且修改 `dist/` 或部署工作流时会自动发布，也可在 Actions 页面手动运行 Deploy GitHub Pages。

- 发布内容：`dist/` 中的静态网页、JSON 数据和 CSV 下载。
- 发布记录：https://github.com/JesseZhao1990/beijing-nanny-guide/actions
- 不依赖后端服务或第三方运行时，不需要在仓库保存云服务密钥。
- 仓库与网站均公开访问。修改资料后，提交并推送 `main`，等待部署任务成功即可。
